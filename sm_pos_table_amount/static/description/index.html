Restaurant Table Order Amount

See the running order amount on every occupied table, directly on the POS restaurant floor plan. The waiter and the manager know how much each table is worth without opening a single order.
Key Features

Live Amount Per Table

Every occupied table shows its current order total, tax included, in your POS currency format.

All Open Orders

If a table holds several open orders, the badge shows the sum, always the full picture.

Zero Configuration

Install and it works. Pure frontend, no settings, no new fields, nothing to migrate.

How To Use

  • Install the module (requires the POS Restaurant module)
  • Open your restaurant POS and go to the floor plan
  • Occupied tables show the order amount above the table number
  • The amount updates as products are added and disappears when the table is paid
